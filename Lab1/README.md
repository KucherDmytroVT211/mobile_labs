# Лабораторна робота 1

## Інструкції із запуску

1. Встановіть [Node.js](https://nodejs.org/) (рекомендовано LTS).
2. Встановіть Expo CLI глобально:
   ```bash
   npm install -g expo-cli
   ```
3. Встановіть залежності проєкту:
   ```bash
   npm install
   ```
4. Запустіть додаток:
   ```bash
   npm start
   ```
5. Відскануйте QR-код у Expo Go (Android/iOS) або натисніть `a`/`i` для запуску на емуляторі.

## Структура
- `App.js` — головний компонент
- `screens/` — екрани додатку
- `assets/` — зображення
